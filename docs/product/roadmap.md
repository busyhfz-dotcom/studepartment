# Product Roadmap

## v0.1.0 — Foundation
- Workspace and CI foundation
- Authentication skeleton
- Scientific identity schema
- Design system baseline

## v0.2.0 — Scientific Identity
- Researcher profile
- Institution affiliation
- ORCID import
- Verification basics

## v0.3.0 — Discovery
- Researcher search
- Lab and institution discovery
- Initial semantic retrieval

## v0.4.0 — Opportunities
- Position ingestion
- Filters
- Opportunity detail
- Save and deadline alerts

## v0.5.0 — AI Matching
- Researcher ↔ researcher
- Researcher ↔ lab
- Researcher ↔ opportunity
- Explainable matching

## v0.6.0 — Connections
- Scientific introduction requests
- Recipient preferences
- Smart inbox
- Quiet mode
- Minimal private conversation

## v0.7.0 — Grant Intelligence
- Grant ingestion
- Eligibility extraction
- Fit analysis

## v0.9.0 — Public Beta
- Security and privacy review
- Abuse operations
- Analytics and feedback loops
- Data export/delete

## v1.0.0 — Initial Public Release
Studepartment must reliably help a qualified researcher understand their scientific identity, discover relevant people/opportunities, understand why they are relevant, and initiate a controlled scientific introduction.
